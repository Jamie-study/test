# 나만의 학습장 '공부콩' ## 1. 목적 - 간호학과 1학년 과목(의학용어, 해부생리, 기본간호학)을 한곳에 정리 - 단원 요약 → 용어 카드 암기 → 퀴즈로 확인 ## 2. 화면 구성 - 홈: 과목 카드 3개 - 과목 → 단원 목록 → 단원 상세 (요약 / 카드 / 퀴즈 탭) ## 3. 기능 - [필수] 단원 추가 · 이름 수정 · 삭제 - [필수] 요약 노트 쓰기 · 수정 · 삭제 (자동 저장) - [필수] 용어 카드 만들기, 눌러서 뒤집기, 알아요/몰라요 표시 - [필수] 객관식 퀴즈 · 점수 (카드로 자동 문제 + 직접 만든 문제) - [선택] 틀린 문제만 다시 풀기, 못 외운 카드만 보기 - [선택] 백업 복사 · 붙여넣기로 되살리기 ## 4. 디자인 - 귀엽고 밝은 파스텔 (핑크 · 민트 · 라벤더), 둥근 카드 - 연두색 콩 캐릭터를 SVG로 직접 그리기 ## 5. 기술 조건 - HTML 파일 1개 · 반응형 (휴대폰 위주, PC는 가운데 한 줄) - 내용은 브라우저에 저장 ## 6. 금지사항 - 인터넷 그림 주소 사용 금지 - 의학 내용 AI가 지어내서 미리 채우기 금지 - 이름 · 연락처 입력 칸 금지
